## 24. Information Security Policy
* **Definitions:**
* *Multi-Factor Authentication (MFA):* Mandatory multi-step verification tracks verifying identity prior to digital system entry.
* *Data Classification Matrix:* Categorizing information assets into Public, Internal, Restricted, or Highly Confidential tiers.
* **Eligibility Rules & Scope:** Binds 100% of network users, hardware devices, and digital applications accessing organizational systems.
* **Responsibility Matrix:** The IT Security Team monitors firewall thresholds and logs; employees adhere strictly to password guidelines.
* **Approval Workflows:** System authorization level escalation -> Manager request -> IT Security validation and token issuance.
* **Operational Procedures:**
* All corporate user profiles must utilize strong password lengths (minimum 14 characters, combining alphanumeric and special characters) paired with active, mandatory Multi-Factor Authentication (MFA). Passwords must be updated every 90 days.
* Sharing active access accounts, encryption tokens, or authentication factors is entirely banned.
* Employees must complete regular security training tracks covering phishing identification, ransomware protection, and operational social engineering threats.
* Security incidents, suspicious emails, or compromised company-provided hardware must be reported to the IT Security Desk within 1 hour of discovery.
* Remote access to the corporate production network must occur exclusively through authorized secure Virtual Private Networks (VPNs) configured on company-owned endpoints.
* **FAQs for RAG Retrieval:**
* *Q: How often must my corporate system password be updated?* A: Every 90 calendar days, matching a minimum length of 14 characters.
* *Q: What is the reporting deadline for a suspected phishing or hardware security compromise?* A: It must be reported to the IT Security Desk within 1 hour of discovery.
